「自我洞察」功能更新设计稿
一、概述
本次更新在侧边栏新增「自我洞察」模块，包含周报、月报、洞察档案三个子功能，同时引入两段式隐私控制机制，让用户在享受 AI 洞察的同时，对个人数据拥有完全的控制权。

设计原则：

用户主动触发为主，自动提示为辅

周报按周生成，去重防打扰

月报完全由用户主动发起

隐私优先，每条数据用户说了算

二、侧边栏「自我洞察」模块
2.1 入口位置
在左侧边栏中，「经验系统」组件上方新增「自我洞察」区域。该区域为可展开/收起的下拉菜单结构，默认展开。

2.2 菜单结构
text
📊 自我洞察
  ├── 📅 周报      → 点击展开周报生成面板
  ├── 📆 月报      → 点击展开月报生成面板
  └── 📂 洞察档案  → 点击进入历史洞察列表页
2.3 样式规范
元素	样式说明
一级标题	字号 14px，字重 600，颜色与侧边栏文字一致，左侧带「📊」图标
二级菜单	字号 13px，字重 400，缩进 16px，左侧带对应图标，悬停时背景色微亮
已生成标记（周报）	本周周报已生成时，菜单项右侧显示「✅ 已生成」灰色标签
有更新标记（周报）	本周周报未生成且有新日记时，右侧显示蓝色小圆点提示
未读标记（洞察档案）	有新洞察未读时，右侧显示小红点
加载状态	生成过程中，菜单项右侧显示旋转加载动画
空状态	洞察档案为空时，显示「暂无洞察报告」占位文字
2.4 后端接口预留
前端代码中将以下接口调用封装为独立服务函数，初期使用 Mock 数据：

GET /api/insight/weekly/status?weekStart=YYYY-MM-DD — 查询指定周是否已生成周报

GET /api/insight/weekly?weekStart=YYYY-MM-DD — 获取周报数据

GET /api/insight/monthly?monthStart=YYYY-MM-DD — 获取月报数据

GET /api/insight/archive — 获取洞察档案列表

GET /api/insight/archive/:id — 获取单份洞察详情

POST /api/insight/generate/weekly — 生成周报

POST /api/insight/generate/monthly — 生成月报

三、周报功能
3.1 生成规则与频率控制
触发方式： 用户主动点击「周报」菜单项发起生成

频率控制（核心）：

系统记录每份周报的生成时间及其覆盖的周范围（周一至周日）

同一周范围内，仅允许生成一次周报

已生成周报的周次，在菜单和日期选择器中标记「✅ 已生成」

用户无法对已生成的同一周重复生成，防止无意义消耗 Token

例外情况：

如果用户在已生成周报后又写入了该周日期范围内的新日记，则允许「重新生成」

重新生成时，系统提示：「该周周报已存在，检测到新增日记，是否更新？」

用户确认后覆盖原有周报，更新洞察档案中的对应条目

提示逻辑：

每周首次打开应用时，检测上一周（默认周范围）是否有新日记且未生成周报

若有，则在侧边栏「周报」菜单项右侧显示蓝色小圆点提示

用户点击后进入生成流程

该提示仅在每周第一次打开应用时检测一次（不反复提醒），且仅本周有效

3.2 时间范围
默认： 分析上一完整自然周（本周一至本周日，基于当前日期推算）的日记数据。

手动选择：

用户点击周报菜单后，弹出日期选择器

支持两种模式：

快捷选择：显示「上一周」「本周」两个快捷按钮

手动选择：点击日历中任意日期，系统自动定位该日期所在周的周一至周日

选定后，界面显示「📅 2026年6月22日 - 6月28日」的明确范围提示

若该周已生成过周报，日期选择器内该周显示「✅ 已生成」标记，用户可查看但无法重复生成（除非有新日记触发重新生成）

3.3 生成内容
本周情绪曲线（每日情绪值折线图）

高频关键词 TOP 5

情绪最低点对应的日期及日记摘要

情绪最高点对应的日期及日记摘要

一句话总结（如「本周整体平稳，周三压力峰值后持续回升」）

3.4 Token 优化策略
只拉取所选 7 天内「纳入分析」状态的日记

每篇日记只取 L0 摘要（一句话概括）和情绪值，不取全文

7 篇摘要总字数通常 < 500 字，单次 API 调用 Token 消耗极低

四、月报功能
4.1 生成规则与频率控制
触发方式： 用户主动点击「月报」菜单项发起生成，无自动提示，无定时任务，无频率限制。

交互流程：

用户点击「月报」菜单

弹出日期选择器，默认选中上一个完整自然月

用户确认后立即生成

结果存入洞察档案

频率控制： 月报不设自动生成，不设去重限制，完全由用户手动触发。用户可以：

每月生成一次（常规使用）

为同一月份重新生成（如新增日记后想更新数据）

为任意历史月份生成月报

生成次数无限制

提示逻辑（仅 UI 提示，不自动生成）：

每月 1 日首次打开应用时，侧边栏「月报」菜单项右侧显示绿色小圆点提示「可生成上月月报」

仅为视觉提示，不自动生成，用户点击后才开始

提示存在一周后自动消失，不再重复提醒（用户知道入口在哪就够了）

4.2 时间范围
默认： 上一个完整自然月（如当前 7 月，则默认 6 月 1 日 - 6 月 30 日）

手动选择：

用户点击月报菜单后弹出月份选择器

支持两种模式：

快捷选择：显示「上个月」「本月」两个快捷按钮

手动选择：点击日历中任意日期，系统自动定位该日期所在月份的第一天至最后一天

选定后，界面显示「📆 2026年6月1日 - 6月30日」的明确范围提示

4.3 生成内容
月度情绪趋势图（周均情绪值柱状图）

月度高频关键词 TOP 10

情绪最低的一周及其代表日记摘要

情绪最高的一周及其代表日记摘要

本月显著模式识别（如「每到周一情绪走低，周四回升」）

本月核心主题总结（一句话）

4.4 Token 优化策略（重点）
月报的数据量远大于周报，需做分层处理：

步骤	操作	Token 消耗
第一步	拉取所选 30 天内「纳入分析」日记的 L0 摘要 + 情绪值 + 日期（约 30 条短文本）	极低（仅读取本地数据）
第二步	首次 API 调用：将 30 条 L0 摘要按周分组，压缩为 5 条「周代表摘要」（每条约 50 字）	约 300-500 Token
第三步	第二次 API 调用：基于 5 条周摘要生成完整月报	约 500-800 Token
总计	两份报告总计消耗	约 800-1300 Token
理论 Token 消耗较直接分析 30 篇全文降低约 85%。

五、两段式隐私控制
5.1 第一段：写入时标记（写作时控制）
在日记编辑器的底部工具栏中，增加隐私状态切换组件，采用三段式按钮组设计：

状态	标识	含义	数据处理方式
纳入分析	🔵 蓝色圆点 + 「分析」	默认状态，允许 AI 读取此日记内容	全文参与周报/月报/洞察分析
仅存储	⚪ 灰色圆点 + 「存储」	AI 不看内容，仅做文字存储	不进入任何 AI 请求上下文，仅保留原文
加密锁定	🔴 红色圆点 + 「锁定」	需要密码才能查看原文，AI 不可见	原文在本地加密存储，查看时需验证密码
交互说明：

三个状态按钮横向排列，点击切换，当前选中状态高亮

状态随日记内容一起保存，可随时修改（修改后需重新保存日记）

默认状态为「纳入分析」，用户可自行更改全局默认值（存放在设置页）

5.2 第二段：事后排除（历史记录控制）
在每条日记的详情页或右键菜单中，增加「从分析中排除」操作：

点击后弹出确认框：「确认将本篇日记从所有 AI 分析中排除？此操作可逆。」

确认后，该日记状态切换为「仅存储」，后续所有洞察任务自动跳过

在日记列表或详情页中，被排除的日记显示 ⚪ 灰色标记，便于识别

支持批量操作：在日记列表页多选后，点击「批量排除分析」

恢复方式： 同样位置提供「重新纳入分析」选项，点击后恢复为「纳入分析」状态。

六、洞察档案
6.1 列表展示
点击「洞察档案」进入历史洞察列表页：

按生成时间倒序排列（最新的在最上面）

每条报告卡片显示：

报告类型标签（「周报」/「月报」）

覆盖日期范围（如「2026年6月22日 - 6月28日」）

生成时间

摘要预览（如「本周整体平稳，周三压力峰值后持续回升」）

未读状态（未读时卡片左侧有蓝色竖条标记）

6.2 详情查看
点击任意报告卡片进入详情页

显示完整报告内容（含情绪曲线、关键词、摘要等）

查看后自动标记为已读（蓝色竖条消失）

提供「导出为 Markdown」按钮，方便用户保存到本地

6.3 删除与清理
每条报告卡片支持右键 → 删除（或卡片右上角删除按钮）

删除前弹出确认框：「确认删除此报告？此操作不可恢复。」

支持批量删除（多选后点击批量删除）

七、数据流与性能要求
7.1 数据读取流程
text
用户触发生成 → 读取隐私标记 → 过滤出「纳入分析」的日记 →
按日期排序 → 提取 L0 摘要 + 情绪值 → 组装 Prompt →
调用 AI API → 解析返回结果 → 存入洞察档案
7.2 性能指标
周报生成时间：< 120 秒（含单次 API 调用）

月报生成时间：< 300 秒（含两次 API 调用）

前端 UI 在分析过程中不卡顿，显示加载骨架屏

所有 AI 调用均在后端异步处理，前端仅等待结果返回

7.3 错误处理
所选日期范围内无「纳入分析」的日记 → 提示「该时间段暂无可用数据」

已生成周报且无新日记 → 提示「该周周报已生成，点击可查看」

AI API 调用失败 → 显示错误提示，允许用户重试

超时处理：设置 60 秒超时，超时后提示「分析超时，请稍后重试」

八、验收要点
编号	验收项	预期结果
1	侧边栏「自我洞察」菜单	显示完整三级菜单，样式符合设计稿
2	周报生成（默认上周）	3 秒内返回完整周报，含情绪曲线、关键词、高低点摘要
3	周报去重	同一周第二次尝试生成时提示已存在，不重复调用 AI
4	周报重新生成	已生成周报的周次有新日记时，允许重新生成并覆盖
5	周报提示	新一周首次打开且有新日记时显示蓝色提示点
6	月报生成	用户点击后弹出日期选择器，6 秒内返回完整月报
7	月报无自动提示	月报不自动触发任何生成行为，仅显示视觉提示点
8	月报日期选择	支持快捷选择「上个月」「本月」及手动选择任意月份
9	隐私状态切换（写作时）	三种状态切换后，存储状态正确，AI 分析按规则过滤
10	事后排除	标记排除后，后续洞察任务自动跳过该日记
11	洞察档案	所有已生成报告存入列表，按时间倒序排列，支持查看和删除
